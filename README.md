# FITUR
Fitur yang tersedia pada program ini:
- Tambah Data: Berfungsi untuk menambah data baru.
- Update Data: Berfungsi untuk mengubah data berdasarkan ID
- Hapus Data: Berfungsi untuk menghapus data berdasarkan ID
- Tampilkan Data: Berfungsi untuk menampilkan semua data yang ada.
- Cari Data: Berfungsi untuk mencari data.
